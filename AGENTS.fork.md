# Rules for this fork

- Read the upstream `AGENTS.md` and `CONTRIBUTING.md` before changing code.
- No Valve files, no Steam account data and no APK in this repository, ever.
- Every test file is wired into `build_files/quest/check.sh` in the same change that adds it.
- I write issues, commits and docs in the first person, about the app, and name hardware by its technical description.
- Each upstream pull request is offered on its own, with a video of the change working and the AI model named.
- Issue drafts are files in `docs/issue-drafts/`; none is posted until I say so.
- The Quest 2 is the target. The Windows VM runtime is out of scope.
