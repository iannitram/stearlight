What: I want the arm64 test launcher to pass QEMU paths that contain spaces intact. `Start-Process -ArgumentList` joins the array with spaces and does not quote it, so a directory such as `F:\Stearlight Test\` splits the `-L`, `-serial`, `-kernel`, `-initrd` and `-drive` values. The path checks only enforce the drive letter, so such a path passes them.
Where: tests/test-arm64.ps1:115-131 (the `$args` array with unquoted paths), :161 (the `Start-Process` call) (code map: docs/code-map.md#tests)
Size: Medium (about 15 changed lines; PowerShell; Windows host)
Serves: none (cleanup)
Done when: a launch from an output directory whose name contains a space starts QEMU with the same argument list, quoted, as a launch from a directory without one. The argument list is logged before start, and the check is on the Windows host.
