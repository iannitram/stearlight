What: I want `steamos-set-timezone` to act only on real zone files. The check `-r` is also true for directories, and the name validator accepts `America`. A root run therefore links `/etc/localtime` to a directory and still exits 0. A non-root run saves `America` as the timezone. Changing `-r` to `-f` fixes both.
Where: system_files/usr/bin/steamos-polkit-helpers/steamos-set-timezone:17-18 (code map: docs/code-map.md#system-files)
Size: Easy (about 2 changed lines in the script and a new test of about 60 lines; POSIX sh, with the test driven from Python 3)
Serves: none (cleanup)
Done when: the locked tests below pass. `America` is not saved and the helper exits 0. `Etc/UTC` is saved by name in the state file. A missing zone is not saved. The root branch is checked by reading the diff, because the test runs as a normal user.

## Qwen brief
Expectation:
- Not root, `steamos-set-timezone America` (a directory under `/usr/share/zoneinfo`): exit 0 and no state file is created.
- Not root, `steamos-set-timezone Etc/UTC`: exit 0 and the file `$XDG_STATE_HOME/stearlight/timezone` contains `Etc/UTC` followed by a newline.
- Not root, `steamos-set-timezone Mars/Olympus` (no such file): exit 0 and no state file is created.
- `steamos-set-timezone ../etc` or an empty argument: exit 2 and `Invalid timezone: ...` on stderr. This is unchanged.
- Fix shape: on line 18 change `[ -r "$zone_file" ]` to `[ -f "$zone_file" ]`. Change nothing else.

Code map snippet:
```sh
#!/bin/sh
# SteamOS's first-run timezone picker invokes this helper through pkexec.
# stearlight has no desktop/polkit agent, so keep the operation small and
# deterministic: persist the selected zone and update /etc/localtime when the
# caller has the privilege to do so.  Returning success is important because
# Steam treats a missing helper as a fatal first-run setup error.
set -eu

zone=${1:-}
case "$zone" in
    ''|/*|*..*|*[^A-Za-z0-9_+./-]*)
        echo "Invalid timezone: $zone" >&2
        exit 2
        ;;
esac

zone_file="/usr/share/zoneinfo/$zone"
if [ -r "$zone_file" ]; then
    if [ "$(id -u)" -eq 0 ]; then
        ln -sfn "$zone_file" /etc/localtime
        printf '%s\n' "$zone" > /etc/timezone
    else
        # The Steam UI still needs to advance when pkexec is unavailable. A
        # later privileged boot hook can apply this value without exposing a
        # general-purpose root shell to the user session.
        state_home=${XDG_STATE_HOME:-${HOME:-/home/stearlight}/.local/state}
        mkdir -p "$state_home/stearlight"
        printf '%s\n' "$zone" > "$state_home/stearlight/timezone"
    fi
fi
exit 0
```

## Tests (locked)
Path: tests/steamos-set-timezone-test.py
```python
#!/usr/bin/env python3
"""Locked tests for steamos-set-timezone, non-root branch (the root branch needs root)."""
import os
import shutil
import subprocess
import tempfile
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
HELPER = ROOT / 'system_files' / 'usr' / 'bin' / 'steamos-polkit-helpers' / 'steamos-set-timezone'
ZONEINFO = Path('/usr/share/zoneinfo')


@unittest.skipIf(os.geteuid() == 0, 'non-root branch only; run as a normal user')
class SetTimezoneNonRootTests(unittest.TestCase):
    def setUp(self):
        self.tmp = Path(tempfile.mkdtemp(prefix='tz-test-'))
        self.addCleanup(shutil.rmtree, self.tmp, True)
        self.state_file = self.tmp / 'state' / 'stearlight' / 'timezone'

    def run_helper(self, zone):
        env = {'PATH': '/usr/bin:/bin', 'HOME': str(self.tmp),
               'XDG_STATE_HOME': str(self.tmp / 'state')}
        return subprocess.run(['sh', str(HELPER), zone], capture_output=True,
                              text=True, timeout=20, env=env)

    @unittest.skipUnless((ZONEINFO / 'Etc' / 'UTC').is_file(), 'needs tzdata')
    def test_real_zone_is_saved_by_name(self):
        result = self.run_helper('Etc/UTC')
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.state_file.read_text(), 'Etc/UTC\n')

    @unittest.skipUnless((ZONEINFO / 'America').is_dir(), 'needs tzdata')
    def test_directory_name_is_not_saved(self):
        result = self.run_helper('America')
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertFalse(self.state_file.exists())

    def test_missing_zone_is_not_saved(self):
        result = self.run_helper('Mars/Olympus')
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertFalse(self.state_file.exists())

    def test_traversal_name_is_rejected(self):
        result = self.run_helper('../etc')
        self.assertEqual(result.returncode, 2)
        self.assertFalse(self.state_file.exists())


if __name__ == '__main__':
    unittest.main()
```
