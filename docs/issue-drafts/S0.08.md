## Check
1. Before updating, record the installed APK version, the number of installed games, and the sign-in state in docs/acceptance/M8.md.
2. Install the newer release APK over the existing one: `adb install -r <release>.apk`. Do not uninstall first.
3. Open Stearlight. Confirm the dashboard appears and I am still signed in to Steam.
4. Run the Steam client update and wait for it to finish.
5. Confirm I am still signed in, all installed games are still listed, and one game launches.
6. Fail if sign-in is lost, a game asks for a reinstall, or the update reports a failure that did not happen.
7. Record the after state and one trimmed log excerpt in docs/acceptance/M8.md.
