title: "S2.13: Send the developer-mode setting only when it changes"
labels: size:medium, kind:wiring, platform:linux
---
What: I send a developer-mode update after every settings change, even when developer mode did not change. With developer mode on and a password set, each update rewrites sshd_config, and with no desktop running it also rewrites the xrdp, sesman, xorg and pam files.
Where: packages/quest-runtime/linux/desktop-ui-bridge.js:153-159 (synchronize and the SetSetting wrapper); the handler is desktop-manager.py:447-450 (code map: docs/code-map.md#quest-linux-bridges)
Size: Medium (about 15 changed lines; JavaScript; the wrapper sits inside a larger function, so a check needs a SteamClient stub)
Serves: M4
Done when: a SetSetting call that leaves developer_mode_enabled unchanged sends no developer call; a call that changes it sends exactly one. Checked with node --check and a stub of SteamClient.Settings.
