labels: size:medium, kind:wiring, platform:linux

What: I want `/dev/ttyAMA0` to stop being writable by every local user. `chmod a+rw` lets any process write lines into the boot log, including fake READY banners. The boot script's own comment says that port carries the diagnostics, so the log cannot be trusted while the mode is open. The boot script's output is already redirected to that port by its root shell, so the mode change should not be needed.
Where: system_files/etc/local.d/arm64-vm.start:98, comment at :23 (code map: docs/code-map.md#system-files)
Size: Medium (about 5 changed lines; POSIX sh; checked by a VM boot)
Serves: none (cleanup)
Done when: `/dev/ttyAMA0` is not mode a+rw. The boot log still reaches the serial port, and the steamframe session still starts. Checked by a VM boot with the serial log captured.
