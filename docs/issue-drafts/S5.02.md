labels: size:medium, kind:wiring

What: I want the signing passwords to come from build inputs, not from the source. The continuous signing block hardcodes storePassword and keyPassword as 'android', so anyone with only the keystore file can use the key.
Where: packages/quest-runtime/app/build.gradle:20-31; CI passes -PquestSigningStore at .github/workflows/build.yml:138-142; the Windows build passes it at post_process/quest/build-apk.ps1:25-32 (code map: docs/code-map.md#build-and-ci)
Size: Medium (about 25 changed lines; Gradle, CI YAML and PowerShell; needs one new repository secret)
Serves: none (cleanup)
Done when: build.gradle contains no literal password. The store and key passwords come from the questSigningStorePassword and questSigningKeyPassword properties, and a build that sets questSigningStore without them fails with a message that names both properties. CI and build-apk.ps1 pass them from secrets. Checked by running git grep for the literal 'android' in the signing block (no hit), and by a continuous CI build that signs with the secret password.
