labels: size:medium, kind:wiring

What: I want the developer-runtime extra to be honored only in debuggable builds. QuestActivity is exported and re-reads its intent in onNewIntent, so any installed app can make it create external-runtime.ready and skip the Linux start.
Where: packages/quest-runtime/app/src/main/java/net/stearlight/quest/QuestActivity.java:136, :165 (marker and extra); packages/quest-runtime/app/src/main/AndroidManifest.xml:27 (exported activity) (code map: docs/code-map.md#quest-app-java)
Size: Medium (about 15 changed lines; Java and manifest for Android, checked on a Quest 2)
Serves: none (cleanup)
Done when: on a release build, starting the activity with developerRuntime=true does not create external-runtime.ready and the Linux start runs. On a debuggable build the flow used by post_process/quest/run-linux-debug.ps1 still works. Checked on a Quest 2 with adb shell am start -e developerRuntime true on each build type.
