What: I want the boot script to print the archive-ready banner only when the Steam archive really extracted. Today a failed `tar` or a missing `RUNSTEAM.sh` still prints the READY line, because the script does not stop on errors there. The failure then shows up later as a Steam start that breaks for no visible reason.
Where: system_files/etc/local.d/arm64-vm.start:122-131 (code map: docs/code-map.md#system-files)
Size: Medium (about 15 changed lines; POSIX sh; checked only by a VM boot)
Serves: M1
Done when: when the `tar` at line 126 fails, the log shows an extraction-failed line and no READY line. When the three `test` checks pass, the READY line prints as before. A global `set -e` is not needed and should not be added, because the rest of the script relies on `|| true`. Checked by a VM boot with a truncated archive passed through `STEARLIGHT_FRAME_STEAM_ARCHIVE`.
