## Check
1. Launch an installed game from the library. Record its title and the release tag.
2. Play for 30 minutes without stopping. Note each time the picture judders or freezes for more than one second.
3. Record frame-time evidence: the median and 99th-percentile frame time from the Steam performance overlay, or from the runtime log, whichever this build provides.
4. Fail on any crash, any restart of the game or dashboard, any ANR, or a stall over one second.
5. Run `adb logcat -d | grep -iE "crash|ANR|signal|fatal"` and record matching lines in docs/acceptance/M4.md. Trim the excerpt.
