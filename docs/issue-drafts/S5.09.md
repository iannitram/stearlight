What: I verify the update bundle's signature on one file, then unpack the same path a second time. The cache directory is writable by the UID that games run as, so a game can swap the file between the two steps and supply its own manifest and root image.
Where: packages/quest-runtime/linux/steam-os-update.py:118-135 (verified_bundle; the signature check is at 130-131 and the unpack at 135) (code map: docs/code-map.md#steam-update)
Size: Hard (about 40 changed lines plus a decision about which directory the update may stage into; Python; the staging owner and the privileges the update runs with are not confirmed in the repo)
Serves: none (cleanup)
Done when: the unpack step reads the bytes that the signature check read, from a path that no other process under the game UID can write. A test that swaps the staged file between the openssl step and the unsquashfs step (both tool calls patched) shows that the swapped file is never unpacked.
