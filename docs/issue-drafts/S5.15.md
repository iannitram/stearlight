title: "S5.15: Stop the tester console giving an unauthenticated root shell"
labels: size:medium, kind:wiring, platform:linux
---
What: I want the optional tester console on the virtio serial port to stop giving a root shell with no login. When the kernel command line carries `stearlight.debug=1`, the boot script runs `/bin/sh -i` as root on `/dev/hvc0` in a loop. Anyone who can reach that virtio console gets root. The flag is set only by the host-side test scripts, so the exposure is limited, but the shell does not need root.
Where: system_files/etc/local.d/arm64-vm.start:31-35; post_process/start-vm.ps1:44; tests/test-arm64.ps1:114 (code map: docs/code-map.md#system-files)
Size: Medium (about 10 changed lines across the boot script and two host scripts; POSIX sh and PowerShell; checked by a VM boot)
Serves: none (cleanup)
Done when: with `stearlight.debug=1` the console still gives a prompt on `/dev/hvc0`, and that prompt runs as an unprivileged user. If the flag is removed instead, both host scripts drop their switch in the same PR. A VM boot with `-DebugConsolePort` shows the prompt, and a boot without the flag starts no shell on `/dev/hvc0`.
