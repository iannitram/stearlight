title: "S5.19: Refuse .. in pkexec command paths"
labels: size:easy, kind:pure-fn, platform:linux
---
What: I want the `pkexec` shim to refuse any command path that contains a `..` segment. Its allowlist glob `steamos-polkit-helpers/*` also matches `..`, so `steamos-polkit-helpers/../../bin/sh` passes the check and runs `/bin/sh`. The image does not install this shim, and git stores it as mode 100755, so the problem is latent. Any later install that runs it with root rights would turn it into a root shell.
Where: system_files/usr/bin/pkexec:18-22 (code map: docs/code-map.md#system-files)
Size: Easy (about 6 changed lines in the script and a new test of about 70 lines; POSIX sh, with the test driven from Python 3; one toolchain for the code)
Serves: none (cleanup)
Done when: the locked test below passes. A command with a `..` segment exits 126 with the "not permitted" message and is not run. Allowed helpers still run with their arguments. Option handling is unchanged.

## Qwen brief
Expectation:
- `pkexec steamos-polkit-helpers/steamos-update check`, run from a directory that contains `steamos-polkit-helpers/steamos-update`, runs that file with the argument `check` and exits with its status.
- `pkexec --keep-cwd steamos-polkit-helpers/steamos-update` runs the helper and exits 0. `pkexec -x steamos-polkit-helpers/steamos-update` exits 2 and prints `pkexec: unsupported option: -x` on stderr.
- `pkexec steamos-polkit-helpers/../../bin/sh` exits 126, prints `pkexec: command is not permitted by stearlight policy` on stderr, and runs nothing.
- `pkexec steamos-polkit-helpers/../steamos-polkit-helpers/steamos-update` also exits 126 and runs nothing. Any `..` segment is refused, even when it resolves to an allowed file.
- `pkexec /bin/sh -c ...` exits 126, because `/bin/sh` is not in the allowlist.
- Fix shape: add one `case "$command" in *..*)` branch before the existing allowlist `case`, printing the existing message and exiting 126. Leave the option loop and the `exec "$@"` line unchanged.
- The absolute form `/usr/bin/steamos-polkit-helpers/../../../bin/sh` cannot be run on a host without that directory. The same `*..*` branch covers it.

Code map snippet:
```sh
#!/bin/sh
# Steam's setup uses pkexec only as a transport for the small steamos-
# polkit-helpers. stearlight has no desktop authentication agent; keep a
# narrow, non-root compatibility shim rather than shipping a general-purpose
# privilege escalator into the image.
set -eu

while [ "$#" -gt 0 ]; do
    case "$1" in
        --disable-internal-agent|--keep-cwd|--user=*) shift ;;
        --) shift; break ;;
        -*) echo "pkexec: unsupported option: $1" >&2; exit 2 ;;
        *) break ;;
    esac
done

command=${1:-}
case "$command" in
    /usr/bin/steamos-polkit-helpers/*|/usr/bin/jupiter-biosupdate|\
    steamos-polkit-helpers/*|jupiter-biosupdate)
        exec "$@"
        ;;
    *)
        echo 'pkexec: command is not permitted by stearlight policy' >&2
        exit 126
        ;;
esac
```

## Tests (locked)
Path: tests/pkexec-allowlist-test.py
```python
#!/usr/bin/env python3
"""Locked tests for system_files/usr/bin/pkexec (the command allowlist)."""
import shutil
import stat
import subprocess
import tempfile
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
PKEXEC = ROOT / 'system_files' / 'usr' / 'bin' / 'pkexec'


def write_stub(path, body):
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text('#!/bin/sh\n' + body + '\n', encoding='utf-8')
    path.chmod(path.stat().st_mode | stat.S_IXUSR | stat.S_IXGRP | stat.S_IXOTH)


class PkexecAllowlistTests(unittest.TestCase):
    def setUp(self):
        self.tmp = Path(tempfile.mkdtemp(prefix='pkexec-test-'))
        self.addCleanup(shutil.rmtree, self.tmp, True)
        self.sandbox = self.tmp / 'sandbox'
        self.sandbox.mkdir()
        self.marker = self.tmp / 'marker'
        # sandbox/steamos-polkit-helpers/../../bin/sh resolves to this stub.
        write_stub(self.tmp / 'bin' / 'sh', f'echo escaped > "{self.marker}"')
        write_stub(self.sandbox / 'steamos-polkit-helpers' / 'steamos-update',
                   f'echo helper "$@" > "{self.marker}"')

    def run_pkexec(self, *args):
        return subprocess.run(
            ['sh', str(PKEXEC), *args], cwd=self.sandbox,
            capture_output=True, text=True, timeout=20,
            env={'PATH': '/usr/bin:/bin'},
        )

    def test_allowed_helper_runs_with_arguments(self):
        result = self.run_pkexec('steamos-polkit-helpers/steamos-update', 'check')
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.marker.read_text().strip(), 'helper check')

    def test_keep_cwd_option_is_still_accepted(self):
        result = self.run_pkexec('--keep-cwd', 'steamos-polkit-helpers/steamos-update')
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertTrue(self.marker.exists())

    def test_unsupported_option_exits_2(self):
        result = self.run_pkexec('-x', 'steamos-polkit-helpers/steamos-update')
        self.assertEqual(result.returncode, 2)
        self.assertFalse(self.marker.exists())

    def test_dotdot_escape_is_refused_and_not_run(self):
        result = self.run_pkexec('steamos-polkit-helpers/../../bin/sh')
        self.assertEqual(result.returncode, 126, result.stderr)
        self.assertIn('not permitted', result.stderr)
        self.assertFalse(self.marker.exists())

    def test_dotdot_inside_allowed_directory_is_refused(self):
        result = self.run_pkexec('steamos-polkit-helpers/../steamos-polkit-helpers/steamos-update')
        self.assertEqual(result.returncode, 126, result.stderr)
        self.assertFalse(self.marker.exists())

    def test_unlisted_command_is_refused(self):
        result = self.run_pkexec('/bin/sh', '-c', f'echo x > "{self.marker}"')
        self.assertEqual(result.returncode, 126)
        self.assertFalse(self.marker.exists())


if __name__ == '__main__':
    unittest.main()
```
