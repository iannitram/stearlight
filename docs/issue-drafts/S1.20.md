What: The controller's Activate ignores the return value of `CreateBooleanComponent` for `/input/system/click` and the other controller components. A failed call leaves the handle at 0, so that input never updates and SteamVR gets no signal and no error.
Where: packages/stearlight-runtime/fake_tracking.cpp:397-399 (system click and the other component calls in Activate), packages/stearlight-runtime/fake_tracking.cpp:171-172 (existing /proximity check to copy) (code map: docs/code-map.md#stearlight-runtime)
Size: Medium (about 20 changed lines; C++ against the OpenVR driver headers; checked only with a driver host or a fake input interface)
Serves: M4
Done when: each component creation checks the result against `vr::VRInputError_None` the way the /proximity check does, and a failure is logged and makes Activate fail. A host test with a fake VRDriverInput that fails `/input/system/click` shows the failure is reported and no handle is left at 0 without a log line.
