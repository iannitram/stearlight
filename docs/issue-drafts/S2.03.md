Where: packages/quest-runtime/app/src/main/java/net/stearlight/quest/BluetoothBridge.java:43-60 (receiver), :150-153 (poll, once-a-second publish) (code map: docs/code-map.md#quest-app-java)
Size: Medium (about 20 changed lines; Java for Android, checked on a Quest 2)
Serves: M7
Done when: the receiver no longer publishes by itself, and a discovery that finds many devices produces only the once-a-second publish from poll. Checked on a Quest 2 by running a discovery near several Bluetooth devices and counting publish writes in the log over 10 seconds.
