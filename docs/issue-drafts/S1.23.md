What: I want a reboot or shutdown request from Steam to survive a non-zero exit of the Steam client. The script runs with `set -euo pipefail`, so `wait "$client_pid"` at line 229 stops the script before the sentinel check at line 233 runs. A Steam exit code that is not zero therefore drops the request.
Where: system_files/usr/share/gamescope-session-plus/gamescope-session-plus:8, :229-239 (code map: docs/code-map.md#system-files)
Size: Medium (about 20 changed lines; bash; the session needs gamescope and a running Steam to check)
Serves: M1
Done when: when the client exits 1 after creating the reboot sentinel, the script still runs the post-client cleanup, still reboots, and then exits with the client's status. The same holds for the shutdown sentinel. A client that exits 0 behaves as before. Checked in a device session by requesting a reboot from a client that exits non-zero.
