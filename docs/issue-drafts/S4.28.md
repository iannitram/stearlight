What: I want the Vulkan present probe to skip its 15-second hold by default and keep it only when a run asks for it. The hold runs after every successful readback, so each manual run pays the wait. No script or CI config in this repo runs this probe today, so the cost falls only on manual runs.
Where: tests/vulkan-present-test.c:152 (`sleep(15);`) (code map: docs/code-map.md#tests)
Size: Medium (about 4 changed lines; C; Vulkan present path, so the result needs a GPU run to check, which puts it in the Medium band even though the edit is small)
Serves: none (cleanup)
Done when: a default run on a GPU build host prints the same `X11 center pixel` line as before and exits without the hold. A run with the opt-in environment variable (the name is chosen in the PR and documented in a comment at the call site) waits 15 seconds before teardown. Both runs report the same readback check result.
