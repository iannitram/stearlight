What: I want the Linux session to stop holding a worker thread. startLinux blocks one of the two pool threads for the whole session, so the 25 ms Bluetooth, 100 ms desktop, 1 s network and device-state pollers share one thread and delay each other.
Where: packages/quest-runtime/app/src/main/java/net/stearlight/quest/QuestActivity.java:26 (pool), :71 (requestLinux), :184-185 (waitFor) (code map: docs/code-map.md#quest-app-java)
Size: Medium (about 15 changed lines; Java for Android, checked on a Quest 2)
Serves: M4
Done when: startLinux no longer occupies a thread from the poller pool, and the pollers keep their configured intervals while a Linux session runs. Checked on a Quest 2 by logging the Bluetooth and desktop poll times during a running session and comparing the gaps with the configured delays.
