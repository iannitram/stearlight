---
id: S2.17
title: "S2.17: Log the stripped present id once, not on every present"
labels: size:medium, kind:wiring, platform:linux
---
What: Every present that carries VkPresentIdKHR calls shim_log, which opens, writes and closes the shim log file and the serial console on each call. At 90 Hz that is 90 file opens and 90 serial writes a second on the present thread.
Where: packages/stearlight-runtime/vulkan_wsi_shim.c:1066 (shim_log in vkQueuePresentKHR), packages/stearlight-runtime/vulkan_wsi_shim.c:618-632 (shim_log opens both files each call) (code map: docs/code-map.md#stearlight-runtime)
Size: Medium (about 10 changed lines; C; the path runs only when the app uses VK_KHR_present_id, so the check is on the device)
Serves: M4
Done when: the stripped-present message is written once per process, or only when STEARLIGHT_VULKAN_TRACE is set like the trace at vulkan_wsi_shim.c:1073. A host check with stubbed file calls counts open() calls across 100 presents and gets at most one, and the device log stops growing with each present.
