What: I decode octal escapes in Steam manifest names one code point at a time. A UTF-8 name such as caf\303\251 becomes two Latin-1 characters, so the alias is created under the wrong path.
Where: packages/quest-runtime/linux/proton-game-launcher.py:16-17; packages/quest-runtime/linux/fex-game-launcher.py:15-16 (both unescape()) (code map: docs/code-map.md#quest-linux-session)
Size: Easy (about 8 changed lines; 2 files; Python; host test)
Serves: M3
Done when: unescape() in both files decodes each run of escapes as bytes and then as UTF-8, so caf\303\251 gives "café". An escape above \377 is returned as typed. Both files give the same result for every case in the locked test.

## Qwen brief
Expectation:
- unescape("plain") returns "plain".
- unescape(r"\101\102") returns "AB".
- unescape(r"caf\303\251") returns "café" (one character for the e-acute).
- unescape(r"a\134b") returns r"a\b" (134 octal is a backslash, and it is not processed again).
- unescape(r"\777") returns r"\777" (above 255, kept as typed).
- unescape("café") returns "café" (literal non-ASCII text is kept).
- Both launcher modules return the same result for each case.

## Tests (locked)
Path: packages/quest-runtime/tests/steam-runtime-unescape.test.py
```python
import importlib.util
from pathlib import Path
import unittest

ROOT = Path(__file__).resolve().parents[1] / 'linux'
MODULES = []
for name, file in (('proton', 'proton-game-launcher.py'), ('fex', 'fex-game-launcher.py')):
    spec = importlib.util.spec_from_file_location(name, ROOT / file)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    MODULES.append(module)

CASES = (
    ('plain', 'plain'),
    (r'\101\102', 'AB'),
    (r'caf\303\251', 'café'),
    (r'a\134b', r'a\b'),
    (r'\777', r'\777'),
    ('café', 'café'),
)


class UnescapeTest(unittest.TestCase):
    def test_octal_escapes_decode_as_utf8_in_both_launchers(self):
        for module in MODULES:
            for source, expected in CASES:
                with self.subTest(module=module.__name__, source=source):
                    self.assertEqual(module.unescape(source), expected)


if __name__ == '__main__':
    unittest.main()
```
