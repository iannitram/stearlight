labels: size:medium, kind:wiring

What: I want every third-party action in the workflows pinned to a full commit SHA, so a moved or compromised tag cannot run new code in a workflow that has write permissions.
Where: .github/workflows/pr-vouch.yml:81 (`mitchellh/vouch/action/check-user@v1`, runs under `pull_request_target` with `issues: write` and `pull-requests: write`); .github/workflows/build.yml (for example `actions/checkout@v4`, `gradle/actions/setup-gradle@v4`) (code map: docs/code-map.md#build-and-ci)
Size: Medium (about 30 changed lines across two or three workflow files; YAML; the SHAs must be looked up, and the check needs a test run of the workflow)
Blocked by: delete this line
Serves: none (cleanup)
Done when: no `uses:` line in .github/workflows/ names a tag or branch instead of a 40-character SHA; each pinned line has a comment with the tag it came from; a manual run of PR Vouch on a test PR still labels it as before.
