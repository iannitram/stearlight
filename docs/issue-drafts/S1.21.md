title: "S1.21: Reopen the Steam web log and drop the stale menu key"
labels: size:medium, kind:state, platform:linux
---
What: The dashboard helper opens `/opt/steam/logs/webhelper.txt` once and keeps the FILE handle. If Steam replaces that log while the wait runs, the loop reads the old file forever; the cached menu key is never cleared, so a stale key can be used and the wait times out.
Where: packages/stearlight-runtime/dashboard_ready.c:15-18 (static FILE and key, one-time fopen), packages/stearlight-runtime/dashboard_ready.c:30 (end of the key scan) (code map: docs/code-map.md#stearlight-runtime)
Size: Medium (about 25 changed lines; C; needs the OpenVR header, and a running Steam to exercise the overlay lookup)
Serves: M4
Done when: the helper reopens the log when its inode changes (or on each poll), and the key comes only from the newest log, so a new log with no match makes the helper report not ready. A host test with a fake overlay table writes a log, replaces it by rename with a different key, and checks the helper returns the new key.
