id: S5.18
title: "S5.18: Stop making every input event node world-writable"
labels: size:medium, kind:wiring, platform:linux
---
What: I want the input event nodes to stop being readable and writable by every local user. `chmod a+rw /dev/input/event*` lets any local process log every keystroke, including typed passwords, or inject input into the session. The fix belongs in a udev rule that gives the session user access through the group that owns the node.
Where: system_files/etc/local.d/arm64-vm.start:115; system_files/etc/udev/rules.d/ (code map: docs/code-map.md#system-files)
Size: Medium (about 20 changed lines; POSIX sh and udev rules; needs the VM's virtual input devices to check)
Serves: none (cleanup)
Done when: after boot, the event nodes are not mode 0666 and are not writable by other users. The session still sees input from the VM's devices: the `STEARLIGHT ARM64 INPUT DEVICES` log lists them, and Steam receives controller input. Checked by a VM boot.
