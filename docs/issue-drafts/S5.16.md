labels: size:medium, kind:pure-fn, platform:linux

What: I want the `steamos-priv-write` helper to refuse destinations that contain a `..` segment. The case pattern `/etc/stearlight/*` also matches `/`, so `/etc/stearlight/../../etc/cron.d/x` passes the check. A caller that is already root then writes any file it names. The image does not install this helper today (the Containerfile copies only select-branch and update), so the problem is latent.
Where: system_files/usr/bin/steamos-polkit-helpers/steamos-priv-write:10-15 (code map: docs/code-map.md#system-files)
Size: Medium (about 6 changed lines; POSIX sh; the write path needs root, so a host test cannot reach it without root)
Serves: none (cleanup)
Done when: a destination with a `..` segment under either prefix is not written and the helper still exits 0. A root run with `/etc/stearlight/setting` still writes the file. Checked by a root test in a disposable container.
