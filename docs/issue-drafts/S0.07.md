## Check
1. Put the keyboard or gamepad in pairing mode. Record the device type.
2. Pair it from the headset, using Horizon Settings > Bluetooth as docs/quest-setup.md describes. Fail if the pairing step does not finish within 60 seconds.
3. Confirm the device shows as connected in the headset and on the dashboard.
4. Type a line in a desktop app (keyboard), or press buttons in a game (gamepad). Confirm each press registers.
5. Forget the device, then pair it again. Confirm the second pairing also completes and responds. Fail if the app needs a restart.
6. Record the result and one trimmed log excerpt in docs/acceptance/M7.md.
