What: I uninstall the app and check that its data is removed, no processes remain, and no leftover folders or packages are left on the headset.
Where: packages/quest-runtime/app/src/main/java/net/stearlight/quest/QuestActivity.java:114-131, packages/quest-runtime/app/src/main/java/net/stearlight/quest/DesktopAppBridge.java:107 (code map: docs/code-map.md#quest-app-java)
Size: Medium (about 30 changed lines; Markdown record; adb from an x86_64 Linux build host to a Quest 2 (Snapdragon XR2 Gen 1, Adreno 650))
Blocked by: S1.01, S1.03, S1.05
Serves: M9
Done when: the check below passes on the headset, and docs/acceptance/M9.md has a dated entry with the release tag, the storage before and after, pass or fail, and the list of any leftovers found.

## Check
1. Start the app, open a desktop app (Chromium), then leave desktop mode. Record the app's storage size from Settings > Apps > Stearlight.
2. Uninstall the app from Settings > Apps > Stearlight > Uninstall.
3. Run `adb shell pm list packages | grep -i stearlight`. Fail if any line prints.
4. Wait 30 seconds, then run `adb shell ps | grep -iE "stearlight|chromium|steam|proot"`. Fail if any process remains.
5. Run `adb shell ls /sdcard/Android/data | grep -i stearlight` and `adb shell ls /sdcard | grep -i stearlight`. Fail if any folder prints.
6. Check the storage screen and record the space returned.
7. Record any leftover in docs/acceptance/M9.md, with the pass or fail result.
