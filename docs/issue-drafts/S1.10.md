What: I end the Linux session at start when an optional Flatpak setup step fails. That step should log its failure and let the session continue.
Where: packages/quest-runtime/linux/prepare-desktop.sh:83-85; packages/quest-runtime/linux/prepare-flatpak.py:31, 43-44 (its check=True calls); packages/quest-runtime/linux/start-session.sh:68 (code map: docs/code-map.md#quest-linux-session)
Size: Medium (about 4 changed lines; shell and Python; the step uses fixed /opt and /usr paths, so the check needs a fake root on the Linux build host)
Serves: M1
Done when: when /opt/quest/prepare-flatpak.py exits 1, prepare-desktop.sh prints one line to stderr that names the step and exits 0, and start-session.sh still reaches the desktop-manager.py start at start-session.sh:69. The KIO call at prepare-desktop.sh:18 can end the session the same way (prepare-desktop-kio.py:34 calls next() with no default); it is not part of this issue.
