What: I want the `steamos-priv-write` helper to say when it skips a write. A non-root caller that passes a destination gets exit 0 and nothing is written. Nothing is logged, so a first-run setting looks saved and is silently lost. The exit 0 is intended, because Steam must keep going, so only the message is new.
Where: system_files/usr/bin/steamos-polkit-helpers/steamos-priv-write:7-17 (code map: docs/code-map.md#system-files)
Size: Easy (about 3 changed lines in the script and a new test of about 50 lines; POSIX sh, with the test driven from Python 3)
Blocked by: S5.16
Serves: none (cleanup)
Done when: the locked test below passes. A non-root call with a destination prints one line to stderr that names the destination and says it was not saved. It still exits 0 and writes nothing. Root calls are unchanged.

## Qwen brief
Expectation:
- Not root, `steamos-priv-write value /etc/stearlight/test-setting`: exit 0, no file created, and stderr holds one line that contains `not saved` and the destination. Example text: `steamos-priv-write: not root, not saved: /etc/stearlight/test-setting`.
- Not root, one argument only (`steamos-priv-write value`): exit 0 and no output at all. Only a skipped write with a destination is logged.
- Root with two arguments: unchanged. Writes the value to the destination under the allowed prefixes.
- Fix shape: inside the `if` at line 7, add an `else` branch that prints the line above to stderr when two arguments were given. Keep `exit 0`.

Code map snippet:
```sh
#!/bin/sh
# Minimal SteamOS compatibility helper.  The standalone image has no mutable
# SteamOS system partition; allow only an explicitly requested destination and
# keep failures non-fatal so Steam's welcome flow can continue.
set -eu

if [ "$#" -ge 2 ] && [ "$(id -u)" -eq 0 ]; then
    value=$1
    destination=$2
    case "$destination" in
        /etc/stearlight/*|/var/lib/stearlight/*)
            mkdir -p "$(dirname "$destination")"
            printf '%s\n' "$value" > "$destination"
            ;;
    esac
fi
exit 0
```

## Tests (locked)
Path: tests/steamos-priv-write-test.py
```python
#!/usr/bin/env python3
"""Locked tests for steamos-priv-write when the caller is not root."""
import os
import subprocess
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
HELPER = ROOT / 'system_files' / 'usr' / 'bin' / 'steamos-polkit-helpers' / 'steamos-priv-write'
DEST = '/etc/stearlight/test-setting'


def run_helper(*args):
    return subprocess.run(['sh', str(HELPER), *args], capture_output=True,
                          text=True, timeout=20, env={'PATH': '/usr/bin:/bin'})


@unittest.skipIf(os.geteuid() == 0, 'non-root behaviour only; run as a normal user')
class PrivWriteNonRootTests(unittest.TestCase):
    def test_exits_zero_and_writes_nothing(self):
        result = run_helper('value', DEST)
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertFalse(Path(DEST).exists())

    def test_says_the_write_was_not_saved(self):
        result = run_helper('value', DEST)
        self.assertIn('not saved', result.stderr)
        self.assertIn(DEST, result.stderr)

    def test_one_argument_stays_silent(self):
        result = run_helper('value')
        self.assertEqual(result.returncode, 0)
        self.assertEqual(result.stderr, '')


if __name__ == '__main__':
    unittest.main()
```
